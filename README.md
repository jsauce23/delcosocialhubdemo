# DELCO Social Hub — demonstration build

A clickable preview of DELCO Social Hub, prepared by Around SA Marketing for
DELCO Heating & Cooling.

## This is a demo

- Every post, photo, request, number and activity entry is a fictional example.
- It is not connected to DELCO's Instagram, Facebook or TikTok accounts.
- Nothing published, scheduled, uploaded or sent inside it goes anywhere.
- The AI studio simulates its output; it is not generating live.
- Changes reset when the page is refreshed — there is no database.

Not licensed for business use.

## Files

- `index.html` — page shell, brand artwork, disclaimers
- `app.js` — the application
- `robots.txt` / `X-Robots-Tag` — keeps the demo out of search results

## Deploying

**Netlify** — Import this repo. No build command; publish directory `.`
(already set in `netlify.toml`).

**GitHub Pages** — Settings → Pages → Deploy from a branch → `main` / `root`.

Needs to be served over http(s), not opened as a local file.
